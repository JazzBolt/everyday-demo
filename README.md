# Everyday — first prototype

This is a static, mobile-friendly **demonstration** of Everyday, the automated family calendar concept.

## Try it locally

Double-click `index.html` to open it in a browser.

## Publish with GitHub Pages

1. Create a **public** GitHub repository called `everyday-demo`.
2. Upload `index.html` and `README.md` to the repository's root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to provide a public URL.

## Important limitations

- No authentication, database, cloud sync, email or calendar integrations.
- Events entered in the browser are stored only in that browser's localStorage.
- The sample review queue resets on refresh.
- Text instructions recognize a narrow demonstration pattern, not AI.
- Do not enter personal/private information into this public prototype.
- GitHub Pages hosts public static websites; it is **not** a production host for the eventual secure application.
